# Illustrative sample photographs

These local images are downloaded from the Unsplash URLs already used by `scripts/seed.ts`, for development preview only. They do not document the specific guitar models, finishes, vintage years or fictional verification grades displayed in the fixture. Each `-detail` image is a square crop of the same source, not a separate authenticated view.

Verified source IDs (https://images.unsplash.com/photo-ID): `1511379938547-c1f69419868d` (studio with guitars) and `1564186763535-ebb21ef5277f` (electric guitar). The eight fixtures intentionally reuse these two illustrations. Several other seed URLs returned HTTP 404, and a working ukulele image was rejected as unsuitable; they are not used. No eight unique instrument photographs are claimed.

Downloaded at width 1000 and square width/height 900, quality 75, using Unsplash image transformations. The preview banner explicitly labels photography illustrative. No image was created by AI.
